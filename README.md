# Aidú Med — sitio web

Sitio estático de Aidú Med (página para médicos, registro y aviso de privacidad), publicado en Netlify.

- `index.html` — página principal
- `registro.html` — registro de médicos en 4 pasos (Netlify Forms: `registro-medico`)
- `privacidad.html` — aviso de privacidad
- `assets/js/config.js` — número de WhatsApp de Aidú Med (los botones se muestran al llenarlo)

Cada cambio que se sube a la rama `main` se publica solo en Netlify.
